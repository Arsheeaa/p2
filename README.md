# Arshia Portfolio — GitHub Pages

Static bilingual portfolio built with **HTML + CSS + vanilla JavaScript + JSON**.

## Edit content
- `data.json` → profile, projects, skills, bilingual text, links
- `assets/images/` → project/workspace images
- `style.css` → visual design and responsive layout
- `app.js` → interactions and rendering

## GitHub Pages
Upload the contents of this folder to a repository. GitHub Pages can publish static HTML/CSS/JS directly from a repository.
Keep `index.html`, `data.json`, `style.css`, `app.js`, and `assets/` at the same level.

No build step is required.
